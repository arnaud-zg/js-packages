Release notes can read like GitHub's "What's Changed": `line` shapes each change, with the presets
`lines.whatsChanged` and `lines.compact` or your own `{summary}`, `{authors}` and `{pr}`.
`commitsVersioning()` keeps a subject's `(#62)` for it. A GitHub release ends on a
`**Full Changelog**` link to the tag before.
